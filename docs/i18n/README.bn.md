# repo-radar

> ৩৬৫ ওপেন সোর্স প্ল্যান #027 · একটি লোকাল ড্যাশবোর্ড যা আপনার সব Git রিপো নজরে রাখে এবং দেখায় কোনগুলোতে আপনার দরকার।

[⬇ Windows · macOS · Linux-এর জন্য ডাউনলোড](https://github.com/rockbenben/repo-radar/releases/latest)

হাতে গুনে রাখার চেয়ে বেশি Git রিপো আপনার আছে। repo-radar সবগুলোর দিকে নজর রাখে আর দেখায় কেবল সেই কয়েকটি, যেগুলোর এখন আপনাকে দরকার — বাকিগুলো মাথা থেকে নামিয়ে রাখুন।

যা দেখতে ভুলে যেতেন, সেগুলো ও তুলে আনে:

- **অসমাপ্ত কাজ** — কমিট, পুশ বা stash না-করা পরিবর্তন, হারিয়ে ফেলার আগেই চিহ্নিত।
- **GitHub আপনার অপেক্ষায়** — খোলা PR, issue আর লাল CI, আপনার লগ-ইন করা `gh` দিয়ে পড়া।
- **ঠান্ডা হয়ে আসা প্রকল্প** — অনেক দিন ছোঁয়া হয়নি, কিংবা রিলিজ দেরি হয়ে গেছে।
- **নজরের বাইরে চলে যাওয়া রিপো** — সব এক স্ক্রিনে, খোঁজা যায়, এক ক্লিকে খোলে।

যেটায় হাত দিতে হবে সেটি সারি হয়ে উপরে উঠে আসে: রিপো-প্রতি একটি, জরুরি অনুসারে সাজানো। ✓ দিয়ে সরিয়ে দিন, সত্যিই কিছু না বদলানো পর্যন্ত সেটি আর ফিরবে না — একটাই ব্যতিক্রম: সরানো stash ৩০ দিন পরে ফিরে আসে, যাতে সত্যিই ভুলে যাওয়াটি চিরতরে হারিয়ে না যায়।

## সমর্থনের পরিধি

| দিক | Windows | macOS | Linux |
| --- | --- | --- | --- |
| ইনস্টল | `.exe` ইনস্টলার | `.dmg` | `.AppImage` |
| উইন্ডো বন্ধ করলে | ট্রেতে চলে যায় | ট্রেতে চলে যায় | বন্ধ হয়ে যায় — চালু রাখতে **লগইনে চালু করুন** |
| পরিবর্তনে নজর | স্ক্যান ডিরেক্টরির নিচের সব রিপো | একই | প্রথম ২০০টি রিপো (সীমা সেটিংসে বাড়ানো বা তুলে দেওয়া যায়) |

সবই আপনার মেশিনে চলে এবং আপনার আগে থেকেই থাকা `git` ব্যবহার করে — অ্যাকাউন্ট নেই, টেলিমেট্রি নেই, কিছুই আপলোড হয় না। GitHub অংশটি (PR, issue, CI) ঐচ্ছিক এবং আপনি যেখানে ইতিমধ্যে লগ-ইন সেই [`gh` CLI](https://cli.github.com/) দিয়ে পড়ে; ওটা বাদ দিলেও বাকিটা চলে।

## ইনস্টল

[Releases](https://github.com/rockbenben/repo-radar/releases) থেকে আপনার প্ল্যাটফর্মের ফাইলটি নিন — Node.js লাগে না। অ্যাপটি কোড-সাইন করা নয়, তাই প্রথমবার চালালে প্রতিটি OS সতর্ক করে:

- **Windows** — SmartScreen-এ *More info → Run anyway*।
- **macOS** — প্রথমবার ডান-ক্লিক → Open। macOS যদি বলে ক্ষতিগ্রস্ত: `xattr -cr /Applications/repo-radar.app`।
- **Linux** — আগে `chmod +x repo-radar-*.AppImage`।

বাইনারিকে এমনি এমনি বিশ্বাস করতে চান না? [নিজেই বিল্ড করুন](../development.md) — শুধু `npm install && npm start`।

প্রথমবার চালিয়ে **স্ক্যান ডিরেক্টরি যোগ করুন** চাপুন এবং সেই ফোল্ডারটি দেখিয়ে দিন যার *ভেতরে* আপনার রিপোগুলো আছে — যেমন `~/Projects`, একটি একটি করে রিপো নয়। সে ৬ স্তর পর্যন্ত নিচে নেমে `.git` আছে এমন সব কিছু খোঁজে, আর বোর্ড ভরে যায়। JSON লাগবে না, রিস্টার্টও না।

## বোর্ড

রিপো-প্রতি একটি কার্ড — স্বাস্থ্যের রং, ব্রাঞ্চ, ওয়ার্কিং ট্রির বিভাজন, ahead/behind, শেষ কমিট, ট্যাগ — সঙ্গে এক ক্লিকে **এডিটর / টার্মিনাল / ফোল্ডার**।

- **খুঁজে বের করা** — সার্চ করুন, কিংবা ভাষা, `#tag` বা সিগন্যাল ল্যাম্প দিয়ে ছাঁকুন। ⌘/Ctrl-K লঞ্চার খোলে।
- **ভিউ সংরক্ষণ** — যেকোনো ফিল্টার + সাজানো + গ্রুপিং, নাম দিয়ে বারবার ব্যবহার।
- **এক সঙ্গে অনেক** — নির্বাচিত রিপোতে fetch / pull / push, বা সবগুলোতে একই shell কমান্ড। একটি রিপো ব্যর্থ হলেও বাকিগুলো থামে না।
- **জায়গাতেই কাজ** — ডিটেইল প্যানেল লাইভ diff সহ কমিট করে, ব্রাঞ্চ বদলায়, পরিবর্তন বাতিল করে, merge হয়ে যাওয়া ব্রাঞ্চ পরিষ্কার করে এবং চাইলে GitHub PR ও CI আনে।
- **নতুন বানানো ও সরানো** — **+ নতুন** রিপো বানিয়ে সরাসরি বোর্ডে বসায়; manifest এক্সপোর্ট / ইমপোর্ট রিপোর তালিকা — পাথ, remote, গ্রুপ, ট্যাগ — অন্য মেশিনে নিয়ে যায়।

উপরের ল্যাম্পগুলোই সতর্কতার ধরন — রিমোট নেই, detached HEAD, পুশ হয়নি, কমিট হয়নি, রিমোটের পেছনে, stash পড়ে আছে। যেগুলো দরকার নেই, ⚙ Settings-এ বন্ধ করে দিন।

আরও দুটি ট্যাব: **পরিসংখ্যান** (এক বছরের কমিট হিটম্যাপ, সবচেয়ে সক্রিয় ও সবচেয়ে নিস্তব্ধ) এবং **কাজের লগ** (একটি তারিখ-পরিসরকে Markdown সাপ্তাহিক রিপোর্ট হিসেবে কপি)।

গাঢ় ইনস্ট্রুমেন্ট-ককপিট থিম, ১৮টি ভাষায়, এবং দুই থিমেই টেক্সট কনট্রাস্ট WCAG AA অনুযায়ী।

## হালনাগাদ থাকা

ডিফল্ট হলো প্রতি ৩০ মিনিটে একটি ফলব্যাক রি-স্ক্যান, সঙ্গে টুলবারের ম্যানুয়াল রি-স্ক্যান — রি-স্ক্যান শুধু লোকাল git অবস্থা পড়ে; কী বদলেছে তা খুঁজতে সে কখনো remote-এর সঙ্গে যোগাযোগ করে না।

ফাইল-ওয়াচ দিয়ে অটো-স্ক্যান **ডিফল্টে বন্ধ**, সেটিংস থেকে চালু করতে হয়। এটিও পুরোপুরি লোকাল, কিন্তু একসঙ্গে কয়েকটি প্রকল্প বিল্ড হলে কার্নেলের নোটিফিকেশন বাফার অনবরত উপচে পড়ে, আর উপচে পড়ার মানেই সেই ইভেন্টগুলো হারিয়ে গেছে যাতে আর ভরসা রাখা যায় — একমাত্র নিরাপদ উত্তর আরেকটি রি-স্ক্যান, এক্সপোনেনশিয়াল ব্যাকঅফ দিয়ে সর্বোচ্চ ৩০ মিনিটে একটি করে। তবুও “কী বদলাল একটু দেখি” ধরনের টুলের জন্য এটি স্থায়ীভাবে বড্ড দামি। চালু করলে নতুন, মুছে ফেলা বা নাম বদলানো রিপো কয়েক সেকেন্ডেই দেখা যায়।

রিপোর নাম বদলান বা সরিয়ে নিন — ট্যাগ, স্টার, আর্কাইভ অবস্থা আর নোট সঙ্গেই থাকে। repo-radar রিপোকে চেনে তার ভেতরে যা আছে তা দিয়ে, কোথায় রাখা আছে তা দিয়ে নয়; তাই সরানো ফোল্ডার একই প্রকল্পই থাকে, নতুন কিছু নয়।

নির্ধারিত ব্যাকগ্রাউন্ড fetch ঐচ্ছিক, এবং এটিই একমাত্র সুবিধা যা নিজে থেকে আপনার remote-এর সঙ্গে কথা বলে। GitHub কলামটিই একমাত্র জিনিস যা না বলেই ঘড়ি মেনে নেটওয়ার্কে যায় — `gh` CLI ইনস্টল থাকলে PR, issue আর CI প্রতি ১২ মিনিটে এবং প্রতিটি রি-স্ক্যানের পরে তার মাধ্যমেই রিফ্রেশ হয়। `gh` না থাকলে, কিংবা GitHub remote না থাকলে, অ্যাপটি পুরোপুরি লোকাল।

## পেছনে চুপচাপ চলে

Windows আর macOS-এ উইন্ডো বন্ধ করলে repo-radar ট্রেতে নেমে যায়, ফলে রি-স্ক্যান, নজরদারি আর GitHub সতর্কতা চলতেই থাকে; Linux-এ উইন্ডো বন্ধ করলে অ্যাপই বন্ধ হয়ে যায়, কারণ সেখানে নির্ভরযোগ্য ট্রে নেই। Windows আর Linux-এ ট্রে আইকনে ক্লিক করলে বোর্ড ফিরে আসে; macOS-এ আইকন তার মেনু খোলে, যেখানে কাজটিই প্রথম আইটেম — আর সব প্ল্যাটফর্মে বন্ধ করুন থাকে সেই মেনুতেই।

বন্ধ করার সময় চলমান git কাজের জন্য — একগুচ্ছ pull, stash মুছে ফেলা — সর্বোচ্চ ১০ সেকেন্ড অপেক্ষা করে, যাতে লেখার মাঝপথে কিছু কাটা না পড়ে আর পুরোনো `.git/index.lock` পড়ে না থাকে। তাতেও না কুলালে সে বেরিয়েই যায় এবং লগে সে কথা লিখে রাখে।

**লগইনে চালু করুন** অন করলে সে আপনার সেশনের সঙ্গেই উইন্ডো ছাড়া চালু হয়। ডেস্কটপ নোটিফিকেশন ঐচ্ছিক এবং কেবল তখনই বাজে যখন GitHub-এর আপনার-অপেক্ষা-রত্ন তালিকায় *নতুন* কিছু আসে — PR, issue বা ব্যর্থ CI; প্রথমবার খোলার সময় কখনোই না।

## কনফিগারেশন

স্ক্যান ডিরেক্টরি, বাদ দেওয়া ফোল্ডার আর খোলার কমান্ড ⚙ Settings → Scanning & open commands-এ বদলানো যায়। বাকি সব `~/.repo-radar/config.json`-এ, যেটি খোলার দরকার কমই পড়ে — কেবল দেখানো সংক্রান্ত পছন্দ (সেভ করা view, থিম, ভাষা, কার্যকলাপের লগ) ব্রাউজারের স্টোরেজে থাকে। পুরো ফিল্ড তালিকা, পাশের ক্যাশ ফাইল আর দ্বিতীয় instance চালানোর environment ভেরিয়েবল [কনফিগারেশন রেফারেন্স](../configuration.md)-এ।

## জানা সীমাবদ্ধতা

- **আপগ্রেড ইচ্ছাকৃতভাবেই ম্যানুয়াল।** অটো-আপডেট নেই: নতুন ইনস্টলার পুরোনোটির উপরে চালান।
- **যে সরানোটি চেনা স্ক্যানে ধরা পড়ে না, সেটি চুপচাপ হারায় না—ইঙ্গিত রেখে যায়।** অটো-মিল না খেললে নতুন কার্ড *«পুরনো পথ থেকে সরানো কপির মতো দেখাচ্ছে»* দেখায় — **স্থানান্তর**-এ ক্লিক করলে ট্যাগ, স্টার আর নোট সঙ্গে আসে। ইঙ্গিত কেবল সেই রিপোতে বাড়ে যেগুলো এই ইনস্টলে অন্তত একবার স্ক্যান হয়েছে (লেজারে রিপোটির remote দেখা থাকতে হবে), আর যে গন্তব্য এখনো স্ক্যান ডিরেক্টরি হিসেবে যোগ করা হয়নি সেখানে কখনোই আসে না।
- **Linux-এ নির্ভরযোগ্য ট্রে নেই**, তাই উইন্ডো বন্ধ করা মানেই অ্যাপ বন্ধ।
- **স্ক্যান ডিরেক্টরির বাইরে একটি একটি করে যোগ করা রিপো এভাবে চেনা যায় না** — সরালে নতুন পথ আপনাকেই দেখিয়ে দিতে হবে।
- **পরিবর্তন বাতিল করা submodule আর ভেতরে বসানো git রিপোতে হাত দেয় না**, এবং সব সাফ হয়েছে না বলে সে কথাটাই জানায়।
