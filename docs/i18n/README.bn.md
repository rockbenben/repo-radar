# repo-radar

> ৩৬৫ ওপেন সোর্স প্ল্যান #027 · একটি লোকাল Git রিপো ড্যাশবোর্ড — একটি ক্রস-রিপো অ্যাকশন কিউ যা উত্তর দেয় এই মুহূর্তে আপনার কী দরকার।

একটি লোকাল Git রিপো ড্যাশবোর্ড যা আপনার মেশিনের প্রতিটি রিপো স্ক্যান করে এবং প্রথমেই আপনার সামনে একটি স্ক্রিন হাজির করে: একটি ক্রস-রিপো **অ্যাকশন কিউ** যা উত্তর দেয় *এই মুহূর্তে আপনাকে কী দরকার* — একটি আইটেমে ক্লিক করুন এবং সরাসরি সেটির উপর ব্যবস্থা নিন। UI তৈরি করা হয়েছে antd 6-এর উপর, একটি গভীর ইনস্ট্রুমেন্ট-ককপিট থিম নিয়ে।

## দ্রুত শুরু

```bash
npm install
npm run build   # build the frontend
npm start       # http://localhost:7420
```

প্রথমবার চালু করলে `~/.repo-radar/config.json` এ একটি ডিফল্ট কনফিগ তৈরি হয়। আপনি যে ডিরেক্টরিগুলো স্ক্যান করাতে চান সেগুলো যোগ করতে `roots` সম্পাদনা করুন (যেমন `D:\Projects` — JSON-এ ব্যাকস্ল্যাশ `D:\\Projects` হিসেবে এস্কেপ করুন), তারপর প্যানেলে **Rescan**-এ ক্লিক করুন।

## Needs you (প্রবেশ স্ক্রিন)

বোর্ডের শীর্ষে থাকা **Needs you** কিউটি একটি ক্রস-রিপো অ্যাকশন কিউ: জরুরিতার ভিত্তিতে র‍্যাঙ্ক করা, প্রতি রিপোর জন্য একটি করে আইটেম — সবচেয়ে জরুরি একমাত্র বিষয়টি, "কতগুলো কমিট হয়েছে" ধরনের আরেকটি অহেতুক ড্যাশবোর্ড নয়।

- **Waiting on you**: অন্যদের খোলা PR, অন্যদের খোলা ইস্যু, ডিফল্ট ব্রাঞ্চে লাল CI (স্থানীয়ভাবে ইতিমধ্যে-প্রমাণীকৃত `gh` ব্যবহার করে ব্যাকগ্রাউন্ডে একত্রিত হয়, প্রতি ১২ মিনিটে রিফ্রেশ হয়, অথবা ↻ দিয়ে ম্যানুয়ালি; আপনার নিজের খোলা PR/ইস্যু WIP হিসেবে গণ্য হয়ে বাদ পড়ে) — সংশ্লিষ্ট GitHub পৃষ্ঠায় সরাসরি যেতে একটি আইটেমে ক্লিক করুন
- **At risk of being lost**: কনফ্লিক্ট / পিছিয়ে থাকা / আনকমিটেড / আনপুশড — যত বেশি সময় ধরে পড়ে থাকে, র‍্যাঙ্ক তত বাড়ে — আনপুশড কাজের জন্য এক-ক্লিকে পুশ করা যায়, বাকি সবগুলো ডিটেইল প্যানেল খোলে
- **Overdue for release**: ট্যাগ করার অভ্যাস আছে এমন রিপো, যেখানে সর্বশেষ ট্যাগের পর ≥৩টি কমিট জমেছে অথচ কোনো রিলিজ হয়নি — শিপ করার একটা ইঙ্গিত (যেসব রিপো কখনো ট্যাগ করে না সেগুলোকে বাদ দেওয়া হয়; সর্বশেষ ট্যাগ নির্বাচিত হয় পুরো রিপো জুড়ে তৈরির সময়ের ভিত্তিতে, বর্তমান ব্রাঞ্চ নির্বিশেষে)
- **Forgotten stash**: ≥৭ দিন ধরে অস্পৃষ্ট অবস্থায় পড়ে থাকা একটি স্ট্যাশ — সরাসরি স্ট্যাশ ইনবক্সে যেতে ক্লিক করুন
- **Dismiss**: নতুন কিছু না ঘটা পর্যন্ত একটি আইটেম সরাতে ✓-এ ট্যাপ করুন — কাউন্ট-ভিত্তিক আইটেমের জন্য কাউন্ট বাড়তে হবে, পরিবর্তন-ভিত্তিক আইটেমের জন্য আরেকটি কমিট দরকার; একটি স্ট্যাশ dismiss করা মূলত একটি স্নুজ যা ৩০ দিন পর আবার সামনে আসে, ফলে সত্যিকার অর্থে ভুলে যাওয়া কোনো স্ট্যাশ চিরতরে চাপা পড়ে না
- ১০টির বেশি আইটেম দেখতে expand করুন; কিছু বাকি না থাকলে "all clear" দেখায়। শীর্ষে একটি সরু ব্যানারে সংকুচিত হয়ে যায়

## Board

- **Cards**: প্রতি রিপোর জন্য একটি কার্ড (প্রতি সারিতে সর্বোচ্চ ৪টি, সমান উচ্চতার)। বাম প্রান্তের রং = স্বাস্থ্য (সবুজ = শান্ত / অ্যাম্বার = মনোযোগ প্রয়োজন / লাল = সতর্কতা)। প্রকৃত নাম · বর্ণনা · ভাষা · ব্রাঞ্চ (main না হলে ফ্ল্যাগ করা) · ওয়ার্কিং-ট্রি ব্রেকডাউন (`+staged ~modified`) · ahead/behind · স্বাস্থ্য ট্যাগ · সর্বশেষ কমিট · রিমোট লিংক · ট্যাগ দেখায়। ফুটারে সবসময় এক-ক্লিক **editor / terminal / folder** থাকে
- **Favorites row**: বোর্ডের শীর্ষে একটি নিবেদিত "★ favorites" সারি — এডিটরে খুলতে ক্লিক করুন
- **Readout cluster**: টপ বারে FLEET / CRIT / WARN / CLEAN গেজ; অ্যালার্ট সংখ্যা ০-এর বেশি হলে জ্বলে ওঠে
- **Click to filter**: একটি কার্ডের ভাষা বা `#tag`-এ ক্লিক করলে তা সরাসরি সার্চ বক্সে চলে যায়
- **Sort**: সর্বশেষ খোলা / সাম্প্রতিকতম সক্রিয় (কমিট সময় অনুসারে) / নাম অনুসারে — ফেভারিটগুলো সবসময় উপরে ভাসতে থাকে
- **Attention lamps**: টপ-বার চিপ যা ইস্যুর ধরন সারসংক্ষেপ করে (no remote / detached HEAD / unpushed / uncommitted / behind / stash); ফিল্টার করতে ক্লিক করুন। "Unpushed" ও "behind"-এর প্রতিটির জন্য এক-ক্লিক "push/pull all" আছে
- **Grouping**: ফোল্ডার অনুসারে / ভাষা অনুসারে / আনগ্রুপড (ফ্ল্যাট)
- **Command palette ⌘/Ctrl-K**: একটি লঞ্চার — নাম টাইপ করুন, এডিটরে খুলতে এন্টার চাপুন (টার্মিনাল / ফোল্ডার / পাথ কপি / রিমোট খোলার জন্য ইনলাইন বাটন)
- **Tag filter**: টপ বারে মাল্টি-সিলেক্ট ট্যাগ (AND — নির্বাচিত প্রতিটি ট্যাগ থাকতেই হবে); একটি কার্ডের `#tag`-এ ক্লিক করলে তা যোগ হয়। ফিল্টার + সর্ট + গ্রুপিং একসাথে একটি নামযুক্ত "view" হিসেবে সংরক্ষিত হয়
- **Inline preview**: একটি কার্ডে "⋯"-তে ক্লিক করলে ডিটেইল প্যানেল না খুলেই সাম্প্রতিক কমিট দেখা যায়
- **Auto-scan (ডিফল্টে বন্ধ)**: টপ বারে একটি "manual ⟳ / auto ⟳" টগল। চালু থাকলে, একটি ফাইল ওয়াচার প্রভাবিত কার্ডগুলো স্বয়ংক্রিয়ভাবে রিফ্রেশ করে (৬০-সেকেন্ড কুলডাউন; কুলডাউনের সময়কার পরিবর্তনগুলো একত্র করা হয়, কখনো বাদ যায় না)। বন্ধ থাকলে, স্টেট শুধু Rescan-এ আপডেট হয়। প্রথম চালুতে একটি স্ক্যান দিয়েই বোর্ড পূরণ হয়
- **Scheduled fetch (ডিফল্টে বন্ধ)**: টপ বারে "fetch: off / every 5–60 min" — ahead/behind তথ্য সতেজ রাখতে পর্যায়ক্রমে ব্যাকগ্রাউন্ডে প্রতিটি রিমোট থেকে fetch করে
- **১৮টি ভাষা**: ⚙ Settings থেকে UI ভাষা পাল্টান (সরলীকৃত/ঐতিহ্যবাহী চীনা, ইংরেজি, জাপানি, কোরিয়ান, স্প্যানিশ, ফরাসি, জার্মান, পর্তুগিজ, রুশ, ইতালীয়, আরবি, হিন্দি, বাংলা, থাই, তুর্কি, ভিয়েতনামী, ইন্দোনেশীয়)। কোনো সংরক্ষিত পছন্দ ছাড়া প্রথমবার দেখলে, UI স্বয়ংক্রিয়ভাবে আপনার ব্রাউজারের ভাষার সাথে মিলে যায় (কিছু না মিললে ইংরেজিতে ফিরে যায়); আরবি স্বয়ংক্রিয়ভাবে RTL-এ পাল্টে যায়। আপেক্ষিক সময়গুলো `Intl` দিয়ে স্থানীয়ভাবে অনুবাদ করা হয়। রিপোর নাম, বর্ণনা ও কমিট বার্তা কখনোই অনূদিত হয় না

## Actions

- কার্ড ফুটারে সবসময় editor / terminal / folder / copy-path বাটন থাকে; একটি খুললে সর্ট করার জন্য ব্যবহৃত একটি "last opened" টাইমস্ট্যাম্প রেকর্ড হয়
- Fetch / pull (`--ff-only`) / push ব্যাচ হিসেবে চলে: একাধিক কার্ড নির্বাচন করুন → টপ বার থেকে ব্যাচ-অ্যাকশন, অথবা পুরো "unpushed" / "behind" অ্যাটেনশন ল্যাম্পে এক-ক্লিক করুন। অগ্রগতি লাইভ দেখায়; একটি রিপো ব্যর্থ হলে বাকিগুলো থেমে যায় না
- **Run a command across repos**: কার্ড নির্বাচন করুন, টুলবারে একটি কমান্ড টাইপ করুন (যেমন `npm install`), এটি নির্বাচিত প্রতিটি রিপোর ডিরেক্টরির ভেতরে সমান্তরালে চলে। "Dry run" আগে দেখায় কোন কোন রিপো প্রভাবিত হবে; "view output" পরে প্রতি-রিপোর ফলাফল দেখায়
- **Stash inbox**: কোনো স্ট্যাশ থাকলে, টপ বারে একটি "stash inbox (N)" লিংক দেখা যায় — প্রতিটি রিপোর প্রতিটি স্ট্যাশ করা পরিবর্তনের তালিকা, প্রতি-আইটেম diff সহ, `apply` / `pop` / `drop` করার সুবিধাসহ
- একাধিক কার্ড নির্বাচন করলে বাল্ক-ট্যাগ প্রয়োগও করা যায়
- **Manifest export / import**: ব্যাকআপ বা মেশিন পরিবর্তনের জন্য **+ new** থেকে সম্পূর্ণ রিপো ম্যানিফেস্ট (পাথ + রিমোট + গ্রুপ + ট্যাগ) এক্সপোর্ট করুন; ইম্পোর্ট করলে যেসব রিপো স্থানীয়ভাবে ইতিমধ্যে আছে সেগুলো পুনরায় গ্রহণ করে এবং যেগুলো নেই সেগুলোর ক্লোনের জন্য তালিকা দেখায়
- config.json-এর `open`-এর অধীনে প্রতিটি টার্গেটের জন্য open কমান্ড কনফিগারযোগ্য; `{path}` রিপো পাথ দিয়ে প্রতিস্থাপিত হয়
- **+ New**: পরবর্তী ক্রম সংখ্যা (যেমন `028-`) এবং আপনার বিদ্যমান সংখ্যাযুক্ত প্রজেক্টগুলোর প্যারেন্ট ডিরেক্টরি প্রস্তাব করে, তারপর ফোল্ডার তৈরি করে, `git init` চালায়, একটি README লেখে, এবং সেটিকে বোর্ডে রিস্ক্যান করে

## Health checks & stats

- নিয়মগুলো (conflicted / no remote / detached HEAD / uncommitted / unpushed / untracked / behind / stash / stale) `health.disabledRules` দিয়ে আলাদাভাবে নিষ্ক্রিয় করা যায়; `staleDays` "stale" থ্রেশহোল্ড নির্ধারণ করে
- **Mergeable branches**: কার্ডগুলো দেখায় কতগুলো লোকাল ব্রাঞ্চ ইতিমধ্যে HEAD-এ মার্জ হয়ে গেছে (বর্তমান ব্রাঞ্চ ও main/master বাদে); ডিটেইল প্যানেল এক-ক্লিক `git branch -d` ক্লিনআপের সুবিধা দেয় (শুধুমাত্র ইতিমধ্যে মার্জ হয়ে যাওয়া ব্রাঞ্চ মুছে ফেলে — নিরাপদ)
- **GitHub (ঐচ্ছিক, স্থানীয়ভাবে ইতিমধ্যে-প্রমাণীকৃত `gh` এর মাধ্যমে)**: "needs you" কিউ প্রতিটি `github.com` রিমোটের জন্য খোলা PR / ইস্যু / ডিফল্ট-ব্রাঞ্চ CI ব্যাকগ্রাউন্ডে একত্রিত করে (রেট-লিমিটেড পোলিং, ডিস্কে সংরক্ষিত, রিস্টার্টে তাৎক্ষণিক)। ডিটেইল প্যানেলও চাহিদামতো খোলা-PR বিস্তারিত ও সর্বশেষ CI রান জিজ্ঞেস করতে পারে; সম্ভব হলে GitHub থেকে রিপোর বর্ণনা ব্যাকফিল করা হয়
- **Stats** ট্যাব: এক বছরের ক্রস-রিপো কমিট হিটম্যাপ (শুধুমাত্র লোকাল ব্রাঞ্চ), সাম্প্রতিকতম সক্রিয়, এবং সবচেয়ে দীর্ঘ সময় ধরে অস্পৃষ্ট থাকা ১০টি রিপো
- **Worklog** ট্যাব: একটি তারিখ পরিসর বেছে নিন ক্রস-রিপো কমিট টাইমলাইন দেখতে (লেখক অনুসারে ফিল্টারযোগ্য — ডিফল্টভাবে "শুধু আমি", আপনার git পরিচয় স্বয়ংক্রিয়ভাবে শনাক্ত করে), এক-ক্লিকে একটি Markdown সাপ্তাহিক রিপোর্ট হিসেবে কপি করার সুবিধাসহ
- একটি কার্ডে ক্লিক করে ডিটেইল প্যানেল খুলুন: সম্পূর্ণ স্বাস্থ্য বিবরণ, মার্জযোগ্য ব্রাঞ্চ, **লোকাল ব্রাঞ্চ সুইচ / তৈরি / বাতিল করুন**, **কমিট ইন প্লেস** (একটি বার্তা টাইপ করুন, এটি কমিট করে) মুলতুবি পরিবর্তনের লাইভ diff সহ, GitHub PR/CI, একটি মিনি ১২-সপ্তাহের হিটম্যাপ, সাম্প্রতিক কমিট, স্ট্যাশ এবং রিমোট

## Organizing repos

- একটি কার্ডকে ফেভারিট করতে ★ দিন (এটি উপরে ভেসে ওঠে); ডিটেইল প্যানেলে ট্যাগ যোগ/বাদ দিন (আপনার আগে ব্যবহার করা ট্যাগ থেকে অটোকমপ্লিট হয়) এবং এর গ্রুপ পরিবর্তন করুন ("auto" ফোল্ডার-নির্ভর গ্রুপিং পুনরুদ্ধার করে)
- **Notes / to-dos**: ডিটেইল প্যানেলে "পরবর্তী কী করব" লিখে রাখুন — এটি কার্ডে দেখা যায়
- **Exclude**: আপনি দেখতে না চাওয়া রিপো লুকান; বাদ দেওয়া রিপোগুলো ডিফল্টভাবে বোর্ড, অ্যালার্ট ও কমান্ড প্যালেট থেকে লুকানো থাকে। টপ বারে "Excluded (N)" আলাদাভাবে সেগুলো দেখতে/পরিচালনা করতে দেয় (ডিটেইল প্যানেল থেকে un-exclude করা যায়)
- পরিবর্তনগুলো তাৎক্ষণিকভাবে প্রয়োগ হয় এবং কোনো Git রিস্ক্যান ছাড়াই config.json-এ লেখা হয়

## Development

```bash
npm run dev     # runs server(7420) + vite(5173) together, frontend proxies /api
npm test        # full server + web test suite + both typechecks
```

স্ট্যাক: Node + Hono (সমস্ত git অ্যাক্সেস `spawn`-এর মাধ্যমে, শূন্য নেটিভ ডিপেন্ডেন্সি), Vite + React 19 + antd 6 (CSS ভেরিয়েবলের মাধ্যমে গভীরভাবে কাস্টমাইজড), লাইভ আপডেটের জন্য chokidar + WebSocket।

## Configuration (config.json)

| Field | Description |
| --- | --- |
| `roots` | স্ক্যান করার রুট ডিরেক্টরি; `.git` থাকা ডিরেক্টরিগুলো রিকার্সিভভাবে খুঁজে বের করে (গভীরতা ≤ ৬) |
| `excludes` | বাদ দেওয়ার ডিরেক্টরির নাম (ডিফল্টে node_modules অন্তর্ভুক্ত) |
| `manualRepos` | কনফিগার করা roots-এর বাইরে ম্যানুয়ালি যোগ করা রিপো পাথ |
| `tags` / `favorites` / `groupOverrides` | প্রতি-রিপো-আইডি ট্যাগ / ফেভারিট / গ্রুপ ওভাররাইড |
| `notes` / `archived` | প্রতি-রিপো-আইডি নোট / আর্কাইভড ফ্ল্যাগ |
| `health` | `{ staleDays, disabledRules }` |
| `open` | এক-ক্লিক ওপেন টার্গেটের জন্য কমান্ড টেমপ্লেট (editor / terminal / explorer) |

`REPO_RADAR_CONFIG` এনভায়রনমেন্ট ভেরিয়েবল কনফিগ ফাইলের পাথ ওভাররাইড করে। সার্ভার শুধুমাত্র `127.0.0.1`-এ শোনে এবং API ও WebSocket উভয় ক্ষেত্রেই Origin হেডার যাচাই করে।
