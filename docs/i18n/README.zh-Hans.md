# repo-radar

> 365 开源计划 #027 · 本地 Git 仓库态势面板——跨仓库「待处理」行动队列，一屏看清现在该我管什么

本地 Git 仓库态势面板：自动扫描发现你的所有仓库，一屏看清每个项目的身份与状态。进门第一屏是跨仓库的「待处理」行动队列——只回答「现在该我管什么」，条目能直接动手。界面基于 antd 6，仪表舱风格深度定制。

## 快速开始

```bash
npm install
npm run build   # 构建前端
npm start       # http://localhost:7420
```

首次启动会在 `~/.repo-radar/config.json` 生成默认配置，编辑 `roots` 加入要扫描的根目录（如 `D:\Projects`，JSON 中反斜杠需转义为 `D:\\Projects`），然后在面板点击「重新扫描」。

## 待处理（进门第一屏）

面板顶部的「待处理」是跨仓库行动队列：按紧迫度排序，每个仓库只报最紧迫的一条，条目点了就能动手——不是又一个「有多少个 commit」的自嗨看板。

- **等我的**：别人开的 open PR、别人提的 open issue、默认分支 CI 变红（后台走本机已登录的 `gh` 汇总，12 分钟刷新，可 ↻ 手动刷新；自己开的 PR/issue 算 WIP，不计入）——点一条直接跳到 GitHub 对应页
- **要丢的活**：冲突 / 落后 / 没提交 / 没推，搁得越久越靠前——没推的可就地一键 push，其余点开详情处理
- **该发版了**：有打 tag 习惯的仓库，最新 tag 之后堆了 ≥3 个提交却一直没发——提醒你交付（从不打 tag 的仓库不打扰；按 tag 创建时间取全库最新 tag，不受当前分支影响）
- **快忘的 stash**：某条 stash 搁置 ≥7 天——点了直达 stash 收纳箱
- **已处理**：点 ✓ 暂时消掉，等「有新的」才回来——计数类要数量变多（又来了新的），改动类要再提交一次；stash 是打盹，30 天后重新提醒（不让真忘的那条永久静音）
- 超过 10 条可展开看全部；一切干净时显示「全部干净」。可折叠成顶部一条细横幅

## 看板

- **卡片**：每个仓库一张卡（一行最多 4 列、等高），左侧色带 = 健康度（绿=安静 / 琥珀=留意 / 红=告警），显示真名 · 描述 · 语言 · 分支（非 main 会标出）· 工作区细分（`+staged ~modified`）· ahead/behind · 健康标签 · 上次提交信息 · 远程链接 · 标签；底部常显「编辑器 / 终端 / 目录」一键打开
- **常用置顶**：看板顶部单独一行「★ 常用」，列出收藏的项目，点一下用编辑器打开
- **读数簇**：顶栏 FLEET / CRIT / WARN / CLEAN 仪表读数，告警数 >0 时点亮
- **点即筛选**：点卡片上的语言或 `#标签`，即把它填进搜索框缩小范围
- **排序**：最近打开 / 最近活跃（提交时间）/ 按名称——收藏项恒排最前
- **告警灯筛选**：顶栏按问题类型汇总（无远程 / 游离 HEAD / 未推送 / 未提交 / 落后 / stash），点击筛选；对「未推送」「落后」可一键「全部 push / pull」
- **分组方式**：按目录 / 按语言 / 不分组（平铺）
- **命令面板 ⌘/Ctrl-K**：启动器——敲名字，回车直接用编辑器打开（行内按钮可选终端 / 目录 / 复制路径 / 打开远程）
- **标签筛选**：顶栏多选标签（AND：须同时带全部标签），点卡片 `#标签` 即加入；连同筛选/排序/分组一起存成「视图」
- **卡片内预览**：卡片上「⋯」弹出最近提交，不用打开详情
- **自动扫描（默认关）**：顶栏「⟳ 手动 / ⟳ 自动」开关。开启后文件监听，仓库有变化时卡片自动刷新（60 秒冷却，期间变更合并补刷不丢失）；关闭时状态只在点「重新扫描」时更新。首次启动仍会扫描一次填充看板
- **定时拉取（默认关）**：顶栏「拉取: 关 / 每 5–60 分钟」，后台定时 fetch 全部远程，保持 ahead/behind 新鲜
- **多语言（18 种）**：⚙ 设置里切换界面语言（简繁中英日韩西法德葡俄意阿印地孟泰土越印尼）。首次访问且无已存偏好时，自动按浏览器语言对齐（匹配不上则用英语兜底）；阿拉伯语自动 RTL；相对时间用 `Intl` 按语言原生本地化。仓库名 / 描述 / 提交信息保持原文不译

## 操作

- 卡片底部常显「编辑器 / 终端 / 目录 / 复制」按钮；打开时记录「最近打开」时间，供排序置顶
- fetch / pull（`--ff-only`）/ push 走批量：勾选多张卡片 → 顶栏批量操作，或对「未推送 / 落后」告警灯一键处理；进度实时显示，单仓库失败不中断
- **批量执行命令**：勾选后在工具条输入命令（如 `npm install`），在每个选中仓库目录下并行执行，「预演」先看将影响哪些仓库，完成后「查看输出」看每仓库结果
- **stash 收纳箱**：有 stash 时顶栏「stash 收纳箱 (N)」进入，跨仓库列出所有搁置的 stash，逐条查看 diff、`apply` / `pop` / `drop`
- 勾选多张卡片还可批量打标签
- **清单导出 / 导入**：＋新增里导出全部仓库清单（路径 + 远程 + 分组 + 标签）备份/换机；导入把本机已存在的重新纳入、并列出不在本机的供克隆
- 打开命令可在 config.json 的 `open` 节自定义，`{path}` 会被替换为仓库路径
- **＋新建**：自动建议下一个编号（如 `028-`）+ 现有编号项目的父目录，建目录 + git init + README + 重扫纳入

## 体检与统计

- 规则（冲突 / 无远程 / 游离 HEAD / 未提交 / 未推送 / 未跟踪 / 落后 / stash / 长期未动）可在 `health.disabledRules` 禁用，`staleDays` 配置「长期未动」阈值
- **可清理分支**：卡片标出已合并进 HEAD（不含当前分支与 main/master）的本地分支数，详情里一键 `git branch -d` 清理（只删已合并的，安全）
- **GitHub（可选，走本机已登录的 `gh`）**：「待处理」后台汇总每个 `github.com` 仓库的 open PR / issue / 默认分支 CI（限流轮询、结果落盘、重启秒显）；详情里另可按需查询开放 PR 明细与最近 CI 运行；仓库描述也会用 GitHub 描述补全
- 「统计」tab：近一年跨仓库提交热力图（仅本地分支）、最近活跃、最久没碰的 10 个
- 「工作记录」tab：选时间段列出跨仓库提交流水（按提交人筛选，默认「只看我」自动认你的 git 身份），可一键复制成 Markdown 周报
- 点卡片开详情弹窗：体检明细、可清理分支、**本地分支切换 / 新建 / 丢弃**、**就地提交（写信息即 commit）与改动 diff**、GitHub PR/CI、近 12 周迷你热力图、最近提交、stash、remote

## 组织仓库

- 卡片点 ★ 收藏（排最前）；详情抽屉里加/删标签（自动补全用过的标签）、改分组（「自动」恢复按目录推导）
- **便签 / 待办**：详情抽屉写「下次做什么」，卡片上会显示
- **排除**：把不想看的仓库排除，默认从看板、告警、命令面板里都收起；顶栏「已排除 (N)」单独查看/管理它们（详情里「取消排除」放回）
- 改动即时生效并写入 config.json，不触发 git 重扫

## 开发

```bash
npm run dev     # server(7420) + vite(5173) 同时起，前端代理 /api
npm test        # server + web 全部测试 + 双 typecheck
```

技术栈：Node + Hono（git 全走 `spawn`，零原生依赖）、Vite + React 19 + antd 6（CSS variables 主题深度定制）、chokidar + WebSocket 实时。

## 配置项（config.json）

| 字段 | 说明 |
| --- | --- |
| `roots` | 扫描根目录列表，递归发现含 `.git` 的目录（深度 ≤ 6） |
| `excludes` | 跳过的目录名（默认含 node_modules） |
| `manualRepos` | 根目录之外手动添加的仓库路径 |
| `tags` / `favorites` / `groupOverrides` | 按仓库 id 的标签 / 收藏 / 分组覆盖 |
| `notes` / `archived` | 按仓库 id 的便签 / 归档 |
| `health` | `{ staleDays, disabledRules }` |
| `open` | 一键打开的命令模板（editor / terminal / explorer） |

环境变量 `REPO_RADAR_CONFIG` 可覆盖配置文件路径。仅监听 `127.0.0.1`，并对 API/WebSocket 做 Origin 校验。
