# repo-radar

> مشروع 365 مفتوح المصدر #027 · لوحة تحكم محلية لمستودعات Git — قائمة إجراءات شاملة لكل المستودعات تجيب عن سؤال ما الذي يحتاج انتباهك الآن.

لوحة تحكم محلية لمستودعات Git تفحص كل مستودع على جهازك وتضع أمامك شاشة واحدة أولاً: **قائمة إجراءات** شاملة لكل المستودعات تجيب عن سؤال *ما الذي يحتاج انتباهك الآن* — انقر على أي عنصر لتتصرف حياله مباشرة. الواجهة مبنية على antd 6 بتصميم يحاكي غرفة قيادة الأجهزة (instrument-cockpit).

## البدء السريع

```bash
npm install
npm run build   # build the frontend
npm start       # http://localhost:7420
```

عند التشغيل الأول يُنشأ ملف إعدادات افتراضي في `~/.repo-radar/config.json`. عدّل `roots` لإضافة المجلدات التي تريد فحصها (مثلاً `D:\Projects` — احرص على كتابة الشرطة المائلة العكسية مرتين هكذا `D:\\Projects` داخل JSON)، ثم انقر على **Rescan** في اللوحة.

## يحتاج انتباهك (شاشة الدخول)

قائمة **Needs you** الموجودة أعلى اللوحة هي قائمة إجراءات شاملة لكل المستودعات: مرتّبة حسب درجة الإلحاح، عنصر واحد لكل مستودع — أهم شيء واحد فقط يحتاج التصرف، وليست لوحة عرض أخرى تباهي بعدد الالتزامات (commits).

- **بانتظارك**: طلبات الدمج (PRs) المفتوحة من آخرين، المشكلات (issues) المفتوحة من آخرين، فشل CI باللون الأحمر على الفرع الافتراضي (تُجمَّع في الخلفية عبر أداة `gh` محلية مسجَّلة الدخول مسبقاً، وتُحدَّث كل 12 دقيقة أو يدوياً بالضغط على ↻؛ طلبات الدمج والمشكلات المفتوحة الخاصة بك تُعدّ عملاً قيد التنفيذ (WIP) وتُستبعد) — انقر على أي عنصر للانتقال مباشرة إلى صفحة GitHub المطابقة
- **معرّضة لخطر الضياع**: تعارضات / متأخرة عن الأصل / تغييرات غير ملتزم بها / التزامات غير مدفوعة، وكلما طال بقاؤها ارتفع ترتيبها — الأعمال غير المدفوعة تحصل على زر دفع بنقرة واحدة، وكل ما عداها يفتح لوحة التفاصيل
- **متأخرة عن الإصدار**: مستودعات معتادة على وضع الوسوم (tags) وتراكم لديها ≥3 التزامات منذ آخر وسم دون إصدار جديد — تنبيه لطرح إصدار (المستودعات التي لا تضع وسومًا مطلقاً تُترك دون إزعاج؛ يُختار آخر وسم حسب وقت إنشائه عبر المستودع كله، بغض النظر عن الفرع الحالي)
- **مخبأ منسي (stash)**: مخبأ (stash) ظل دون لمسٍ لمدة ≥7 أيام — انقر للانتقال مباشرة إلى صندوق المخبآت
- **تجاهل العنصر**: اضغط ✓ لمسح عنصر إلى أن يستجد شيء جديد — العناصر المعتمدة على العدّ تحتاج إلى ازدياد العدد، والعناصر المعتمدة على التغيير تحتاج إلى التزام إضافي؛ تجاهل مخبأ هو غفوة مؤقتة (snooze) تعود للظهور بعد 30 يوماً بحيث لا يُسكَت مخبأ منسي فعلاً إلى الأبد
- التوسيع لما بعد 10 عناصر لرؤية كل شيء؛ تظهر عبارة "all clear" حين لا يتبقى شيء. تنكمش إلى شريط رفيع أعلى الشاشة

## اللوحة

- **البطاقات**: بطاقة واحدة لكل مستودع (حتى 4 في كل صف، بارتفاع متساوٍ). لون الحافة اليسرى = الحالة الصحية (أخضر = هادئ / كهرماني = يحتاج انتباهاً / أحمر = تنبيه). تعرض الاسم الحقيقي · الوصف · اللغة · الفرع (يُعلَّم إن لم يكن main) · تفصيل شجرة العمل (`+staged ~modified`) · متقدم/متأخر عن الأصل · وسوم الحالة الصحية · آخر التزام · رابط المستودع البعيد · الوسوم (tags). التذييل يحتوي دائماً أزرار **المحرر / الطرفية / المجلد** بنقرة واحدة
- **صف المفضلة**: صف مخصص "★ favorites" أعلى اللوحة — انقر لفتحه في محررك
- **مجموعة المؤشرات**: مقاييس FLEET / CRIT / WARN / CLEAN في الشريط العلوي؛ تُضاء أعداد التنبيهات عندما تكون > 0
- **النقر للتصفية**: انقر على لغة بطاقة أو `#tag` لإدراجها مباشرة في مربع البحث
- **الفرز**: آخر فتح / الأكثر نشاطاً مؤخراً (حسب وقت الالتزام) / حسب الاسم — المفضلة تطفو دائماً إلى الأعلى
- **مصابيح التنبيه**: شرائح في الشريط العلوي تلخّص أنواع المشكلات (بلا مستودع بعيد / رأس منفصل (detached HEAD) / غير مدفوع / غير ملتزم به / متأخر عن الأصل / مخبأ)؛ انقر للتصفية. لكل من "unpushed" و"behind" زر "دفع/سحب الكل" بنقرة واحدة
- **التجميع**: حسب المجلد / حسب اللغة / بلا تجميع (مسطّح)
- **لوحة الأوامر ⌘/Ctrl-K**: مُطلِق سريع — اكتب اسماً واضغط Enter لفتحه في محررك (أزرار مضمّنة للطرفية / المجلد / نسخ المسار / فتح المستودع البعيد)
- **تصفية الوسوم**: اختيار متعدد للوسوم في الشريط العلوي (بمنطق AND — يجب أن تحمل البطاقة كل وسم مُختار)؛ انقر على `#tag` في بطاقة لإضافته. التصفية + الفرز + التجميع تُحفظ معاً كـ "عرض" (view) مسمّى
- **معاينة مضمّنة**: "⋯" على البطاقة يعرض الالتزامات الأخيرة دون فتح لوحة التفاصيل
- **فحص تلقائي (معطّل افتراضياً)**: مفتاح تبديل "manual ⟳ / auto ⟳" في الشريط العلوي. عند التفعيل، تُحدَّث البطاقات المتأثرة تلقائياً عبر مراقب ملفات (فترة تهدئة 60 ثانية؛ التغييرات أثناء فترة التهدئة تُدمج ولا تُفقد أبداً). عند الإيقاف، لا تُحدَّث الحالة إلا عند الضغط على Rescan. اللوحة تُملأ دوماً بفحص واحد عند التشغيل الأول
- **جلب مجدوَل (معطّل افتراضياً)**: "fetch: off / every 5–60 min" في الشريط العلوي — يجلب دورياً من كل مستودع بعيد في الخلفية للحفاظ على حداثة معلومات التقدّم/التأخر
- **18 لغة**: بدّل لغة الواجهة من إعدادات ⚙ (الصينية المبسطة/التقليدية، الإنجليزية، اليابانية، الكورية، الإسبانية، الفرنسية، الألمانية، البرتغالية، الروسية، الإيطالية، العربية، الهندية، البنغالية، التايلاندية، التركية، الفيتنامية، الإندونيسية). عند الزيارة الأولى بلا تفضيل محفوظ، تُطابق الواجهة لغة متصفحك تلقائياً (وتعود إلى الإنجليزية إن لم تُطابق أي لغة)؛ تتحول العربية تلقائياً إلى اتجاه من اليمين لليسار (RTL). الأوقات النسبية تُعرَّب محلياً عبر `Intl`. أسماء المستودعات والأوصاف ورسائل الالتزام تبقى دائماً دون ترجمة

## الإجراءات

- تذييل البطاقة يعرض دائماً أزرار المحرر / الطرفية / المجلد / نسخ المسار؛ فتح أحدها يسجّل طابع زمني "آخر فتح" يُستخدم في الفرز
- الجلب / السحب (`--ff-only`) / الدفع تُنفَّذ كدفعات: حدّد عدة بطاقات ← نفّذ إجراءً جماعياً من الشريط العلوي، أو اضغط بنقرة واحدة على مصباح تنبيه كامل من نوع "unpushed" / "behind". يظهر التقدّم مباشرة؛ فشل مستودع واحد لا يوقف البقية
- **تنفيذ أمر عبر المستودعات**: حدّد بطاقات، اكتب أمراً في شريط الأدوات (مثل `npm install`)، يُنفَّذ بالتوازي داخل مجلد كل مستودع محدَّد. "Dry run" يعاين أولاً أي المستودعات ستتأثر؛ "view output" يعرض بعد ذلك نتيجة كل مستودع على حدة
- **صندوق المخبآت (Stash inbox)**: عند وجود أي مخبأ، يظهر رابط "stash inbox (N)" في الشريط العلوي — يسرد كل تغيير مخبّأ عبر كل المستودعات، مع فرق (diff) لكل عنصر وأزرار `apply` / `pop` / `drop`
- تحديد عدة بطاقات يتيح لك أيضاً تطبيق الوسوم بشكل جماعي
- **تصدير/استيراد القائمة (Manifest)**: صدّر قائمة المستودعات الكاملة (المسار + المستودعات البعيدة + المجموعة + الوسوم) من **+ new** للنسخ الاحتياطي أو نقل الأجهزة؛ الاستيراد يتبنّى من جديد المستودعات الموجودة محلياً بالفعل ويسرد التي لا تزال غير موجودة لاستنساخها
- أمر الفتح قابل للتهيئة لكل هدف عبر `open` في config.json؛ يُستبدل `{path}` بمسار المستودع
- **+ New**: يقترح رقم التسلسل التالي (مثل `028-`) والمجلد الأصل لمشاريعك المرقّمة الحالية، ثم ينشئ المجلد وينفذ `git init` ويكتب ملف README ويعيد فحصه في اللوحة

## فحوصات الحالة الصحية والإحصاءات

- يمكن تعطيل القواعد (متعارض / بلا مستودع بعيد / رأس منفصل / غير ملتزم به / غير مدفوع / غير متعقَّب / متأخر عن الأصل / مخبأ / راكد) كل واحدة على حدة عبر `health.disabledRules`؛ يحدّد `staleDays` عتبة اعتبار المستودع "راكداً"
- **الفروع القابلة للدمج**: تُعلِّم البطاقات عدد الفروع المحلية المدموجة بالفعل في HEAD (باستثناء الفرع الحالي وmain/master)؛ توفّر لوحة التفاصيل تنظيفاً بنقرة واحدة عبر `git branch -d` (لا يحذف سوى الفروع المدموجة بالفعل — إجراء آمن)
- **GitHub (اختياري، عبر `gh` محلية مسجَّلة الدخول مسبقاً)**: تجمع قائمة "needs you" طلبات الدمج/المشكلات المفتوحة وحالة CI للفرع الافتراضي لكل مستودع بعيد على `github.com` في الخلفية (استقصاء مقيَّد بمعدل، يُحفظ على القرص، وفوري عند إعادة التشغيل). يمكن للوحة التفاصيل أيضاً الاستعلام عن تفاصيل طلب الدمج المفتوح وآخر تشغيل لـ CI عند الطلب؛ تُستكمل أوصاف المستودعات من GitHub عند توفرها
- تبويب **الإحصاءات (Stats)**: خريطة حرارية سنوية للالتزامات عبر كل المستودعات (الفروع المحلية فقط)، والأكثر نشاطاً مؤخراً، وأكثر 10 مستودعات لم تُلمس منذ أطول فترة
- تبويب **سجل العمل (Worklog)**: اختر نطاق تاريخ لرؤية جدول زمني للالتزامات عبر كل المستودعات (قابل للتصفية حسب المؤلف — يفترض افتراضياً "أنا فقط" عبر اكتشاف هوية Git الخاصة بك تلقائياً)، مع نسخ بنقرة واحدة كتقرير أسبوعي بصيغة Markdown
- انقر على بطاقة لفتح لوحة التفاصيل: تفصيل كامل للحالة الصحية، الفروع القابلة للدمج، **تبديل / إنشاء / تجاهل الفروع المحلية**، **الالتزام في مكانه** (اكتب رسالة، فيتم الالتزام) مع فرق حي للتغييرات المعلَّقة، طلب دمج/CI على GitHub، خريطة حرارية مصغّرة لـ 12 أسبوعاً، الالتزامات الأخيرة، المخبآت، والمستودعات البعيدة

## تنظيم المستودعات

- ضع نجمة ★ على بطاقة لإضافتها للمفضلة (تطفو إلى الأعلى)؛ أضف/احذف وسوماً في لوحة التفاصيل (إكمال تلقائي من الوسوم التي استخدمتها سابقاً) وغيّر مجموعتها ("auto" يعيد التجميع المستنتج من المجلد)
- **ملاحظات / مهام**: دوّن "ما التالي" في لوحة التفاصيل — يظهر على البطاقة
- **الاستبعاد**: أخفِ المستودعات التي لا تريد رؤيتها؛ المستودعات المستبعدة تُخفى افتراضياً من اللوحة والتنبيهات ولوحة الأوامر. "Excluded (N)" في الشريط العلوي يتيح لك عرضها/إدارتها بشكل منفصل (إلغاء الاستبعاد من لوحة التفاصيل)
- التغييرات تُطبَّق فوراً وتُكتب إلى config.json دون إطلاق إعادة فحص لـ Git

## التطوير

```bash
npm run dev     # runs server(7420) + vite(5173) together, frontend proxies /api
npm test        # full server + web test suite + both typechecks
```

المكدّس التقني: Node وHono (كل الوصول إلى git عبر `spawn`، بلا أي تبعيات أصلية native)، وVite وReact 19 وantd 6 (مخصَّص بعمق عبر متغيرات CSS)، وchokidar وWebSocket للتحديثات الحية.

## الإعدادات (config.json)

| الحقل | الوصف |
| --- | --- |
| `roots` | المجلدات الجذرية المراد فحصها؛ يكتشف تكرارياً المجلدات التي تحتوي على `.git` (بعمق ≤ 6) |
| `excludes` | أسماء المجلدات المراد تخطيها (تتضمن node_modules افتراضياً) |
| `manualRepos` | مسارات مستودعات أُضيفت يدوياً، خارج الجذور المهيَّأة |
| `tags` / `favorites` / `groupOverrides` | تجاوزات الوسوم / المفضلة / المجموعة لكل معرّف مستودع |
| `notes` / `archived` | ملاحظات / علامة الأرشفة لكل معرّف مستودع |
| `health` | `{ staleDays, disabledRules }` |
| `open` | قوالب الأوامر لأهداف الفتح بنقرة واحدة (المحرر / الطرفية / مستكشف الملفات) |

متغيّر البيئة `REPO_RADAR_CONFIG` يتجاوز مسار ملف الإعدادات. يستمع الخادم فقط على `127.0.0.1` ويتحقق من ترويسة Origin في كل من واجهة API وWebSocket.
